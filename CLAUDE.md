# JD-1184 — working notes

Personal site of Jafar Dabbagh. Solar-system-as-navigation hero; sections are
celestial bodies (see README for the map).

## Architecture invariants

- The hero canvas is **fixed, full-viewport, pointer-events: none**. R3F
  raycasts from events bubbling on `#page-root` (`eventSource` +
  `eventPrefix="client"`). Never give the canvas wrapper pointer events.
- The 3D scene and DOM overlays communicate through
  `components/hero/store.ts` — positions are written per-frame into a plain
  module object; only `hovered` goes through React state. Keep setState out
  of frame loops.
- Scroll progress drives the genie collapse: each body lerps along a
  quadratic bezier from orbit to a screen-space dock slot. The system docks
  into a **floating centered pill** (`NavBar.tsx`); the DOM pill and the
  scene must agree through `slotCenters`/`sunSlotX`/`pillBounds`/`BAR_TOP`/
  `BAR_H` in the store. Slot anchor y is `BAR_TOP + 24`.
- Homepage sections are full-viewport scenes (`min-h-svh`, full-bleed) paged
  by mandatory lenis snap (`SectionSnap`, desktop pointers only) — keep each
  scene's content inside one viewport height on desktop.
- The garden planet texture is generated from `biosphere()` in
  `data/garden.ts` — change growth stages there, never hardcode colors.
- **The Sanctum** (`/garden`, `components/sanctum/`) is a guided 3-zone walk
  (Room → Threshold → Living Sanctum). Like the hero, the in-canvas scene and
  the DOM overlay bridge through plain module objects (`lib/store.ts` pointer
  look, `shaders/wind.ts` `windUniforms`) — R3F context does **not** cross the
  canvas, so pass primitives as props and keep setState out of frame loops.
  The journey reuses the `data/gardenPaths.ts` node graph (room/threshold
  prepended in `lib/journey.ts`) and `data/gardenFeatures.ts` plaque content.
  Quality is four tiers (`SanctumQualityManager`); HDRI IBL is **ultra-only**
  (the analytic light rig is the verified baseline — the HDR probe can wash PBR
  white on software-GL). Real assets are CC0 under `public/sanctum/`; the loader
  + decoders live in `lib/assets.ts` — never commit non-CC0 assets there.
  The game layer (quests/secrets/achievements) is data in `lib/quests.ts` plus
  a persistent zustand store in `lib/progress.ts` (hydrate after mount only);
  progress advances by **proximity tripwires** (`SanctumQuestSensor` reading
  `playerState`), never by clicks. WASD in the Living Sanctum auto-enters
  free-roam via `sanctumControl.setFreeRoam` — overlay and rig both subscribe.
- **Sanctum look**: one law drives ground colour *and* texture blend —
  `groundTint` (a multiplier over the terrain textures, never absolute paint)
  and `groundMoss` in `lib/terrain.ts`; grass tufts and litter read the same
  law. Zone moods (`lib/moods.ts`) are eased per frame but **initialise from
  the zone the scene opens in** — deep links (`?sanctumStart=<node>`) must not
  fade in from the room. `?sanctumQuality=` forces a tier and `window.__sanctum`
  (dev) exposes scene/camera/renderer for look-tuning. The CSS film grade
  (`sanctumGrade.css`) is the only grading the low tier gets — phones land
  there, so keep atmosphere cheap enough for it.
- Content JSON in `content/` is generated by `scripts/import_wordpress.py`;
  don't hand-edit migrated essays.
- **Signal Layer relays** (`app/api/signals/*`, helpers in `lib/signals/`)
  never show visitors setup detail or raw upstream errors — they answer with
  `offlineCopy` from `data/signals.ts` and log the real reason; missing env
  names appear only in `npm run dev`. Strava refresh tokens rotate (persisted
  via optional Upstash in `lib/signals/tokenStore.ts`); Spotify's expire 6
  months after authorization. Setup + pre-flight: `docs/signals-setup.md`,
  `npm run signals:check`. Never draw Strava/Spotify logos — brand rules.
- `data/email-dispatch-log.json` is the forever-dedupe for broadcasts; it was
  baselined so the back catalogue is never emailed. Don't clear it.

## Style

- Palette/typography live in `app/globals.css` (`@theme`): space black,
  warm ink, starlight gold, hairlines at 12% white. Fraunces (display),
  Cormorant Garamond (essay body), IBM Plex Mono (micro-labels, `.label`).
- Mono labels are uppercase with 0.28em tracking. Hairline borders
  everywhere, no heavy strokes, no rounded corners except planets and the
  docked nav pill.
- Use Tailwind v4 canonical class forms (`text-[8px]!`, `bg-linear-to-t`,
  `aspect-3/4`, `border-hairline`, quarter-rem spacing) — the Problems pane
  stays at zero.
