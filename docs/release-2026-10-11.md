   and one shared site segment; configure the values in Vercel production.

   Keep `NEWSLETTER_AUTOMATION_ENABLED` false until the inbox acceptance passes.

   suppression, and unsubscribe. Verify provider DNS status and review a draft.
6. Approve production release separately. This branch does not apply migrations,
   configure production secrets, send real email, or merge itself.

## Compatibility and rollback

Existing reading routes, source content, and public project history remain.
Active project IDs change to `axom`, with compatibility for the old Sanctum start
parameter and stored visits. A missing newsletter configuration returns 503.
The old direct broadcast API is retired; use the manual or explicitly activated automatic workflow.

To roll back a released application, promote the preceding verified Vercel
production deployment. The new newsletter table can remain unused; do not drop
pending records as a rollback shortcut. Disabling `RESEND_API_KEY` stops new
signup sends, while native Resend unsubscribe remains available in delivered mail.
